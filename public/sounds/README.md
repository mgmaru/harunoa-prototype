# 通知音ファイル配置ガイド

このディレクトリには、ポモドーロ機能の通知音ファイルを配置してください。

---

## 必要なファイル

| ファイル名 | 用途 | 備考 |
|-----------|------|------|
| `bell.mp3` | ベル音 | 集中終了時などに使用 |
| `chime.mp3` | チャイム音 | 休憩終了時などに使用 |

---

## ファイル仕様

| 項目 | 推奨値 |
|------|--------|
| 形式 | MP3（ブラウザ互換性のため必須） |
| 長さ | 1〜3秒 |
| ファイルサイズ | 100KB以下 |

---

## 音声ファイルの配置方法

### 手順

1. 音声ファイル（MP3形式）を用意する
2. ファイル名を `bell.mp3` または `chime.mp3` に変更する
3. このディレクトリ（`public/sounds/`）に配置する

### 重要なポイント

- **ファイル名は固定**です（`bell.mp3`、`chime.mp3`）
- ファイル名が異なると音声が再生されません
- コードでは `/sounds/{ファイル名}.mp3` の形式で参照されています

```
public/
└── sounds/
    ├── README.md    ← このファイル
    ├── bell.mp3     ← 集中終了時の通知音
    └── chime.mp3    ← 休憩終了時の通知音
```

---

## 通知音の変更方法

通知音を変更したい場合は、以下の手順で簡単に差し替えできます。

### 手順

1. 新しい音声ファイル（MP3形式）を用意する
2. ファイル名を変更対象と同じ名前にする
   - ベル音を変更 → `bell.mp3`
   - チャイム音を変更 → `chime.mp3`
3. 既存のファイルを上書きする
4. ブラウザのキャッシュをクリアする（またはスーパーリロード: Ctrl+Shift+R）

### 注意事項

- **ソースコードの変更は不要**です
- ファイル名さえ同じであれば、どんな音声でも使用できます
- 音量は端末側でも調整可能です

- 音量は適度に調整してください（端末側でも調整可能）
- モバイルブラウザでは、ユーザー操作後でないと音声が再生されない場合があります

---

## トラブルシューティング

| 問題 | 原因 | 解決方法 |
|------|------|----------|
| 音が鳴らない | ファイル名が間違っている | `bell.mp3` / `chime.mp3` に修正 |
| 音が鳴らない | ファイル形式がMP3でない | MP3形式に変換する |
| 音が鳴らない | ブラウザのキャッシュ | Ctrl+Shift+R でスーパーリロード |
| 音が鳴らない | 設定で無効化されている | 設定画面で「通知音」を有効化 |
| 変更が反映されない | キャッシュが残っている | ブラウザのキャッシュをクリア |
