### Firestoreセキュリティルール作成 (2026-02-01)

INT-003（複数ユーザー間のデータ分離）のデータベースレベルでの保護として、Firestoreセキュリティルールを作成しました。

**作成ファイル**:
- `firestore.rules` - セキュリティルール定義
- `firebase.json` - Firebase CLI設定

**セキュリティルールの概要**:
- 認証必須: すべての操作に認証が必要
- ユーザー分離: 各ユーザーは自分のデータのみアクセス可能（`request.auth.uid == resource.data.userId`）
- userID変更禁止: 更新時にuserIdの変更を禁止
- 入力検証: 必須フィールドとデータ型を検証

**対象コレクション**:
- `users` - ユーザー情報
- `projects` - プロジェクト
- `sessions` - 作業セッション
- `settings` - ユーザー設定
- `presets` - ポモドーロプリセット

**デプロイ方法**:
```bash
# Firebase CLIでデプロイ
firebase deploy --only firestore:rules

# または Firebase Console から直接設定
```
