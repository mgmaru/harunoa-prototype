# 結合テスト計画書 (Integration Test Plan)

docs/implementation/ 配下の実装仕様書から、**機能連携**や**システム全体に関わる挙動**（単体テストではカバーしきれない項目）を抽出しました。
これらのテストは、関連する機能の実装が完了したタイミングで実施することを推奨します。

## 1. コア機能連携テスト (Auth, Project, Timer)

**実施タイミング**: `03_timer.md` 実装完了後

| ID | カテゴリ | テスト項目 | 関連機能 | 期待値 |
|:--:|:---:|---|---|---|
| INT-001 | 認証・ルーティング | 未認証でのアクセス制限 | Auth, Routing | `/timer`, `/history`, `/analytics` 等へ直接アクセス時、ログイン画面へリダイレクトされること |
| INT-002 | 認証・ルーティング | ログイン後の遷移 | Auth, Routing | ログイン成功後、直前にアクセスしようとしたページ、またはホームへ遷移すること |
| INT-003 | セッション分離 | 複数ユーザー間のデータ分離 | Auth, Firestore | ユーザーAでログイン中に、ユーザーBのプロジェクトやセッションデータが見えない・アクセスできないこと |
| INT-004 | 計測・プロジェクト | プロジェクト切替時の計測継続 | Timer, Project | 計測中に別プロジェクトの「計測開始」を選択時、警告ダイアログが表示され、承認後に旧計測が停止・保存され、新計測が開始されること |
| INT-005 | 計測・履歴 | 計測停止後のデータ保存 | Timer, History | 計測停止後、即座に履歴画面で該当セッション（開始・終了・時間・メモ）が確認できること |
| INT-006 | 計測・履歴 | 長時間計測の保存 | Timer, History | 日付を跨ぐ計測（例: 23:00-25:00）を行い、停止後、履歴上で正しく日付ごとに按分（または表示）されていること |

## 2. データ整合性・可視化テスト (History, Analytics, Settings)

**実施タイミング**: `06_settings.md` 実装完了後

| ID | カテゴリ | テスト項目 | 関連機能 | 期待値 |
|:--:|:---:|---|---|---|
| INT-011 | 履歴・集計 | セッション編集の集計反映 | History, Analytics | 履歴画面でセッションの時間を変更・削除した後、集計画面（グラフ・表）の数値が即座に再計算され整合していること |
| INT-012 | 履歴・集計 | 日付跨ぎセッションの集計 | History, Analytics | 日付を跨ぐセッション（例: 1/1 23:50 ~ 1/2 00:10）が、集計画面で1/1に10分、1/2に10分として計上されること |
| INT-013 | プロジェクト・集計 | アーカイブ済みプロジェクトの除外 | Project, Analytics | プロジェクトをアーカイブした後、そのプロジェクト自体が集計画面の選択肢から消える、または集計対象外となること（仕様依存） |
| INT-014 | 設定・履歴 | CSVエクスポートの内容確認 | Settings, History | エクスポートしたCSVに、現在の履歴データが全件正しく含まれていること（文字化けなし、フォーマット正） |
| INT-015 | アカウント | ログアウト時のデータクリア | Auth, Store | ログアウト後、ブラウザ上の状態（Store）がクリアされ、別ユーザーでログインしても前のユーザーのキャッシュが表示されないこと |

## 3. 応用機能・非機能テスト (Pomodoro, Notification, Offline, Archive)

**実施タイミング**: 全機能実装完了後

| ID | カテゴリ | テスト項目 | 関連機能 | 期待値 |
|:--:|:---:|---|---|---|
| INT-021 | ポモドーロ・タイマー | タイマー連携 | Pomodoro, Timer | タイマー開始時にポモドーロが連動して開始され、タイマー停止時にポモドーロも停止（リセット）すること |
| INT-022 | 通知・設定 | 通知設定の反映 | Notification, Settings | 設定画面で「通知音OFF」にした場合、ポモドーロ終了時に音が鳴らないこと。「通知音ON」で選択した音が鳴ること |
| INT-023 | 通知・設定 | 通知権限ハンドリング | Notification, Settings | ブラウザ通知ブロック時に設定画面でその旨が表示され、通知タイミングではアプリ内バナーで代替通知されること |
| INT-024 | オフライン | オフライン計測と同期 | Offline, Timer, Sync | 通信断中に計測開始・停止を行い、通信復帰後に自動的にサーバーへデータが送信・保存されること |
| INT-025 | オフライン | オフライン中の画面遷移 | Offline, SPA | 通信断中にアプリ内の画面遷移（キャッシュ済み）が可能で、操作（例：メモ編集）がキューに蓄積されること |
| INT-026 | データ管理 | 自動アーカイブ動作 | Archive, History | 1年以上前のデータを持つアカウントでログイン時（または集計画面表示時）、自動的に古いデータがアーカイブ済みとなり、通常一覧から消えること |
| INT-027 | データ管理 | アーカイブデータのCSV出力 | Archive, Settings | CSVエクスポート機能を使用した際、自動アーカイブされた過去データも含めて出力されること |

## 4. エッジケース・異常系テスト

| ID | カテゴリ | テスト項目 | 関連機能 | 期待値 |
|:--:|:---:|---|---|---|
| EDGE-001 | 同期 | 複数端末での競合 | Sync, Realtime | PCとスマホで同時に同じセッションを編集した場合、後に保存した方の内容が反映されること（Last Write Wins） |
| EDGE-002 | 計測 | ブラウザクラッシュ復帰 | Timer, Persist | 計測中にブラウザを強制終了し、再起動・アクセスした際、計測中の状態（経過時間・プロジェクト）が復元されること |
| EDGE-003 | 設定 | プリセット削除の制約 | Settings, Pomodoro | 現在使用中のポモドーロプリセットを削除しようとした際、エラーメッセージが表示され削除できないこと |
| EDGE-004 | ネットワーク | リトライ上限後の動作 | Offline, Toast, Sync | 同期リトライが上限（例: 3回）を超えた場合、ユーザーに「同期失敗」が通知され、手動リトライボタンが表示されること |
