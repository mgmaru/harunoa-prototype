## 2. 前提条件

### 2.1 必要なもの

| 項目 | 説明 |
|------|------|
| Node.js | v18以上 |
| npm | 依存パッケージがインストール済み |
| サービスアカウントキー | Firebase Admin SDK用の認証ファイル |
| ステージング環境へのアクセス | https://harunoa-prototype.vercel.app |

### 2.2 サービスアカウントキーの配置

サービスアカウントキーが以下のパスに配置されていることを確認してください：

```
_local/firebase-service-account.json
```

**未配置の場合の取得手順**:

1. Firebase Console（https://console.firebase.google.com）にアクセス
2. プロジェクト「harunoa-4cb92」を選択
3. 左上の歯車アイコン → 「プロジェクトの設定」
4. 「サービス アカウント」タブを選択
5. 「新しい秘密鍵の生成」をクリック
6. ダウンロードしたJSONファイルを `_local/firebase-service-account.json` に配置

> **注意**: このファイルは `.gitignore` に含まれているため、Gitにコミットされません。

### 2.3 Firebaseクォータの確認

テストデータ作成スクリプトはFirebase Admin SDKを使用します。Firebaseのクォータ制限（RESOURCE_EXHAUSTED）が発生している場合は、クォータがリセットされるまで待ってください（通常24時間）。

## 4. テスト実行手順

### 4.1 ユーザーIDとプロジェクトIDの取得

#### ユーザーIDの取得

Firebase Consoleから取得：
1. Firebase Console → Authentication → Users
2. テストに使用するユーザーの「ユーザーUID」をコピー

**現在のテストユーザー**: `FLnpmsp04oNomAlGXaBlYDBl8983`

#### プロジェクトIDの取得

Firebase Consoleから取得：
1. Firebase Console → Firestore Database
2. `projects` コレクションを選択
3. 該当ユーザーのプロジェクトのドキュメントIDをコピー

または、ステージング環境のアプリから取得：
1. https://harunoa-prototype.vercel.app にログイン
2. プロジェクト一覧で「計測開始」ボタンにカーソルを合わせる
3. URLに含まれる `projectId=` の値をコピー

**例**: `mQBgfkTQzfWkiCYVYsW0`（HaruNoa開発プロジェクト）

### 4.3 ページネーションテストの実施

#### テスト環境

- URL: https://harunoa-prototype.vercel.app
- ブラウザ: Chrome、Firefox、Safari など

#### テスト手順

1. **ステージング環境にログイン**
   - https://harunoa-prototype.vercel.app にアクセス
   - Googleアカウントでログイン

2. **履歴画面を開く**
   - ナビゲーションから「履歴」をクリック
   - または直接 https://harunoa-prototype.vercel.app/history にアクセス

3. **日付フィルタを設定**
   - 「今日」ボタンをクリック
   - または、テストデータを作成した日付をカレンダーで選択

4. **テスト項目の確認**

| No | 確認項目 | 確認方法 | 期待結果 |
|:--:|----------|----------|----------|
| 1 | 1ページ目の表示 | 履歴一覧を確認 | 50件のセッションが表示される |
| 2 | ページ情報 | ページネーション部分を確認 | 「1 / 2」と表示される |
| 3 | 全件数 | ページ下部を確認 | 「全55件」と表示される（既存セッション含む） |
| 4 | 「次へ」ボタン | クリック | 2ページ目に遷移し、残り5件が表示される |
| 5 | 「前へ」ボタン | クリック | 1ページ目に戻り、50件が表示される |

## 6. トラブルシューティング

### 6.1 スクリプト実行時のエラー

| エラー | 原因 | 対処法 |
|--------|------|--------|
| `サービスアカウントキーが見つかりません` | キーファイルが未配置 | 「2.2 サービスアカウントキーの配置」を参照 |
| `RESOURCE_EXHAUSTED` | Firebaseクォータ制限 | 24時間後に再実行 |
| `PERMISSION_DENIED` | サービスアカウントの権限不足 | Firebase Consoleで権限を確認 |

### 6.2 テスト時の問題

| 問題 | 原因 | 対処法 |
|------|------|--------|
| セッションが表示されない | 日付フィルタが異なる | 「今日」ボタンをクリックして日付を確認 |
| ページネーションが表示されない | セッション数が50件以下 | スクリプトの実行結果を確認 |
| ログインできない | セッション切れ | 再度Googleアカウントでログイン |

**create-test-sessions-staging.mjs**:
- 作成件数: 55件（固定）
