# 受け入れテストシナリオ（HaruNoa）

関連ドキュメント：requirements.md 11節

---

## 概要

本ドキュメントは、HaruNoa v2（MVP）の受け入れテストシナリオを定義する。
要件定義書の「受け入れ条件」に基づいて作成。

---

## 1. プロジェクト管理

### 1.1 プロジェクト作成

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | ホーム画面で「+ 新規作成」をクリック | モーダルが開く |
| 2 | プロジェクト名「英語学習」を入力 | |
| 3 | 色を選択（または自動割当） | |
| 4 | 「作成」をクリック | モーダルが閉じ、一覧に「英語学習」が追加される |

### 1.2 プロジェクト編集

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | プロジェクトの「編集」をクリック | 編集モーダルが開く |
| 2 | プロジェクト名を「TOEIC学習」に変更 | |
| 3 | 「保存」をクリック | 一覧の名前が「TOEIC学習」に更新される |

### 1.3 プロジェクトアーカイブ

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | プロジェクトの「アーカイブ」をクリック | 確認ダイアログが表示される |
| 2 | 「アーカイブする」をクリック | プロジェクトが一覧から消える |
| 3 | 「アーカイブ」画面を開く | アーカイブしたプロジェクトが表示される |
| 4 | 「復帰」をクリック | プロジェクトが通常一覧に戻る |

## 2. 計測機能

### 2.1 計測開始〜停止

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 計測画面でプロジェクトを選択 | |
| 2 | 「計測開始」をクリック | 集中モード画面に遷移する |
| 3 | 経過時間が増加することを確認 | 1秒ごとに更新される |
| 4 | 「一時停止」をクリック | 経過時間が停止する |
| 5 | 「再開」をクリック | 経過時間が再び増加する |
| 6 | 「停止」をクリック | セッションが保存され、ホームに戻る |
| 7 | 履歴画面を開く | 保存されたセッションが表示される |

### 2.2 計測中の離脱確認

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 計測中に「戻る」をクリック | 確認ダイアログが表示される |
| 2 | 「計測を継続して戻る」をクリック | 計測が継続したまま前画面へ |
| 3 | 再度「戻る」→「計測を停止して戻る」 | 計測が停止し、セッションが保存される |

## 3. 履歴管理

### 3.1 セッション編集

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 履歴画面でセッションの「編集」をクリック | 編集モーダルが開く |
| 2 | 開始時刻を30分前に変更 | |
| 3 | 「保存」をクリック | 計測時間が再計算される |
| 4 | 集計画面を確認 | 合計時間が更新されている |

### 3.2 バリデーション

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 開始時刻を終了時刻より後に設定 | エラー「開始時刻は終了時刻より前にしてください」 |
| 2 | 終了時刻を未来の時刻に設定 | エラー「終了時刻は現在時刻より後にできません」 |

### 3.3 セッション削除

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 「削除」をクリック | 確認ダイアログが表示される |
| 2 | 「削除」をクリック | セッションが一覧から消える |
| 3 | 集計画面を確認 | 合計時間が再計算されている |

## 4. 集計・グラフ

### 4.1 期間別表示

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 集計画面を開く | 当週の集計が表示される |
| 2 | 「日」タブをクリック | 当日の集計に切り替わる |
| 3 | 「月」タブをクリック | 当月の集計に切り替わる |
| 4 | 「年」タブをクリック | 当年の集計に切り替わる |
| 5 | 「＜」ボタンをクリック | 前の期間に移動する |
| 6 | 「＞」ボタンをクリック | 次の期間に移動する |

### 4.2 グラフ表示

| No | 確認項目 | 期待結果 |
|:--:|----------|----------|
| 1 | 棒グラフ | プロジェクト別の作業時間が横棒グラフで表示される |
| 2 | 円グラフ | プロジェクトの割合がパーセント表示される |
| 3 | 合計時間表 | プロジェクト名、合計時間、割合が表形式で表示される |

## 5. ポモドーロ

### 5.1 プリセット管理

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | プリセット管理画面を開く | デフォルト（25分/5分）が表示される |
| 2 | 「+ 新規作成」をクリック | 作成モーダルが開く |
| 3 | 名前「長時間集中」、集中50分、休憩10分で作成 | 一覧に追加される |
| 4 | 「利用する」をクリック | バッジが「利用中」に変わる |

### 5.2 バリデーション

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | 集中時間を24分に設定 | エラー「集中時間は25分以上で設定してください」 |
| 2 | 休憩時間を4分に設定 | エラー「休憩時間は5分以上で設定してください」 |
| 3 | 休憩時間を11分に設定 | エラー「休憩時間は10分以内で設定してください...」 |

### 5.3 休憩スキップ

| No | 操作 | 期待結果 |
|:--:|------|----------|
| 1 | ポモドーロを使用して計測開始 | |
| 2 | 集中時間終了後、休憩画面になる | 休憩中の表示に切り替わる |
| 3 | 「スキップ」をクリック | 休憩が終了し、次の集中フェーズが開始 |
