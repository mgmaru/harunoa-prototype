# 受け入れテストシナリオ（HaruNoa）

関連ドキュメント：requirements.md 11節

---

## 概要

本ドキュメントは、HaruNoa v2（MVP）の受け入れテストシナリオを定義する。
要件定義書の「受け入れ条件」に基づいて作成。

### テストシナリオ数

| カテゴリ | テスト数 |
|----------|:--------:|
| 1. プロジェクト管理 | 6 |
| 2. 計測機能 | 6 |
| 3. 履歴管理 | 8 |
| 4. 集計・グラフ | 2 |
| 5. ポモドーロ | 7 |
| 6. 通知 | 5 |
| 7. データ管理 | 3 |
| 8. 認証 | 4 |
| 9. 複数端末 | 2 |
| 10. オフライン対応 | 4 |
| 11. 非機能要件 | 2 |
| **合計** | **49** |
