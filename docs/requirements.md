# 要件定義書（HaruNoa）

作成日：2026-01-20

---

## 1. ドキュメント概要

本ドキュメントは、日々の作業を **「プロジェクト単位」** で記録・可視化するツール **HaruNoa** の要件定義書である。

- 記録対象：作業時間（必須）、作業メモ（任意）
- 主な用途：日次の振り返り、週/月の時間配分の把握、ペース作り（ポモドーロ）

---

## 2. 用語

| 用語         | 意味                                                   |
| ------------ | ------------------------------------------------------ |
| プロジェクト | 作業をまとめる単位（例：英語学習、個人開発、案件A）    |
| セッション   | タイマー計測の1回分（開始〜終了）                      |
| 計測         | タイマーで作業時間を記録する行為                       |
| ポモドーロ   | 集中時間＋休憩時間のサイクルで作業を進める方式         |
| 集中モード   | 計測中の最小UIフルスクリーン画面（集中支援用）         |
| プリセット   | ポモドーロ設定（集中/休憩時間など）を名前付きで保存したもの |

---

## 3. 前提・スコープ

### 3.1 対象ユーザ

- v2（MVP）は **単一ユーザ（自分1人）** を想定

### 3.2 対応環境

| 項目         | v2の要件                                         |
| ------------ | ------------------------------------------------ |
| ブラウザ     | Google Chrome（PC/スマホ）                       |
| 画面         | レスポンシブ対応（スマホは「計測操作」を最優先） |
| 言語         | 日本語                                           |
| タイムゾーン | 端末のローカル時間（日本利用想定）               |

### 3.3 非スコープ（v2ではやらない）

| 事項                                   |
| -------------------------------------- |
| チーム/複数ユーザでの共同利用          |
| タスクを細分化した工程管理（ガント等） |
| 高度な分析（AI提案、目標最適化など）   |
| アカウント削除機能                     |

## 4. 機能要件

### 4.1 画面一覧（v2）

| 画面             | 目的               | 主な機能                                                               |
| ---------------- | ------------------ | ---------------------------------------------------------------------- |
| プロジェクト一覧 | 管理の入口         | 作成/編集（名前変更）/アーカイブ、合計時間の表示                       |
| 計測（タイマー） | すぐ計測する       | プロジェクト選択、開始/停止/一時停止、メモ入力（任意）                 |
| 集中モード       | 計測中の没入を支援 | 計測開始時に自動表示、最小UI、メモ入力（任意）                         |
| 履歴             | 後から見返す/直す  | セッション一覧、手動修正、削除                                         |
| 集計・グラフ     | 可視化             | 日/週/月/年の集計、プロジェクト別の棒グラフ、円グラフ                  |
| 設定             | 使い勝手調整       | ポモドーロ設定、通知ON/OFF、データ出力、ログアウト                     |

---

### 4.2 プロジェクト管理

#### 4.2.1 プロジェクト作成

| 項目             | 仕様                                               |
| ---------------- | -------------------------------------------------- |
| プロジェクト数   | 無制限                                             |
| プロジェクト名   | 必須（重複許可するが非推奨）                       |
| 色               | 任意（未指定なら自動割当）                         |

#### 4.2.2 色の自動割当ルール

- 定義済みカラーパレット（10色程度）から順番に割当
- すべて使用済みの場合は最初の色に戻る（ループ）

#### 4.2.3 プロジェクト一覧の表示項目

- プロジェクト名
- 期間合計（当日/当週/当月の切替、デフォルト当週）
- 最終計測日

#### 4.2.4 編集/アーカイブ

| 操作         | 仕様                                               |
| ------------ | -------------------------------------------------- |
| 名前変更     | 可能                                               |
| アーカイブ   | 通常一覧から除外（データは残す）                   |
| 集計への反映 | アーカイブ済みプロジェクトのセッションは集計に含めない |
| 復帰         | アーカイブ済みから復帰可能                         |

---

### 4.3 作業計測（タイマー）

#### 4.3.1 計測の基本ルール

- 同時に計測できるのは **1プロジェクトのみ**
- 計測状態：`Stopped` ⇄ `Running` ⇄ `Paused`

| 操作     | 挙動                                               |
| -------- | -------------------------------------------------- |
| 開始     | 選択したプロジェクトで計測開始、開始時刻を保存     |
| 一時停止 | 計測を止めるがセッションは継続（経過は加算停止）   |
| 再開     | 一時停止中の計測を再開                             |
| 停止     | セッションを確定（終了時刻を保存、合計時間を計算） |

#### 4.3.2 集中モード（Focus Mode）

計測中に「見る/考える」要素を減らし、作業に没入できる状態を作る。

| 項目         | 仕様                                                           |
| ------------ | -------------------------------------------------------------- |
| 遷移         | 計測開始と同時に自動遷移                                       |
| 表示方式     | アプリ内で画面全体を覆う専用UI（Fullscreen APIは使用しない）   |
| 常時表示     | プロジェクト名、経過時間（最大視認性）、操作ボタン、計測状態   |
| メモ入力     | 任意・自由記述1欄（入力中も計測継続）                          |
| 離脱確認     | 確認ダイアログを表示（「計測継続して戻る」or「計測停止して戻る」） |
| 別プロジェクト開始 | 2ステップ確認必須（警告→確定操作）                       |

#### 4.3.3 タイマー操作のエラーハンドリング

| エラー状況               | 挙動                                                   |
| ------------------------ | ------------------------------------------------------ |
| 操作がサーバに反映されない | エラー表示＋リトライボタン                             |
| リトライ失敗（3回）      | 「オフラインモードで継続」を案内、ローカル記録に切替   |

#### 4.3.4 プロジェクト切替時の挙動

- 計測中に別プロジェクトを開始した場合：現在の計測を自動停止→新プロジェクトの計測開始
- UI上で注意表示（例：「現在の計測を終了して切り替えます」）

#### 4.3.5 作業メモ（任意）

セッションごとにメモ（短文）を保存できる（例：やったこと/詰まった点/次やること）

---

### 4.4 履歴（セッション管理）

#### 4.4.1 履歴の表示

| 項目           | 仕様                                     |
| -------------- | ---------------------------------------- |
| フィルタ       | 日付（今日/昨日/カレンダー選択）         |
| 表示項目       | プロジェクト名、開始/終了時刻、計測時間、メモ |
| ソート順       | 新しい順（デフォルト）                   |
| ページネーション | 1ページあたり50件                      |

#### 4.4.2 手動修正

| 修正可能項目 | 備考                                     |
| ------------ | ---------------------------------------- |
| 開始時刻     | 押し忘れ対応用                           |
| 終了時刻     | 押し忘れ対応用                           |
| 計測時間     | 直接入力で補正（開始/終了は自動計算可）  |
| メモ         | 自由修正                                 |

修正後は集計値・グラフを再計算する。

#### 4.4.3 手動修正のバリデーション

| 条件               | エラー内容                                           |
| ------------------ | ---------------------------------------------------- |
| 開始時刻 > 終了時刻 | 「開始時刻は終了時刻より前にしてください」、保存拒否 |
| 終了時刻が未来     | 「終了時刻は現在時刻より後にできません」、保存拒否   |

#### 4.4.4 削除

セッションを削除できる（取り消し確認を表示）

#### 4.4.5 日付跨ぎの扱い

| ケース               | 処理                                               |
| -------------------- | -------------------------------------------------- |
| 日付跨ぎ             | 時間を日付ごとに按分（例：23:50〜00:10 → 前日10分、翌日10分） |
| 複数日跨ぎ（24時間超） | 各日に24時間を上限として按分                       |

---

### 4.5 集計・可視化

| 項目       | 仕様                                     |
| ---------- | ---------------------------------------- |
| 集計粒度   | 日 / 週 / 月 / 年                        |
| 週の定義   | 月曜日開始                               |
| 表示内容   | プロジェクト別合計時間（表・棒グラフ）、作業割合（円グラフ）、期間合計 |

---

### 4.6 ポモドーロ

#### 4.6.1 ポモドーロとセッションの関係

- ポモドーロの記録はセッション（作業時間）とは **別管理**
- ポモドーロの集中/休憩時間は、プロジェクトの作業時間には含めない
- あくまで「集中と休憩のリズムを作る手段」として扱う

#### 4.6.2 プリセット

| 項目       | 仕様                                     |
| ---------- | ---------------------------------------- |
| デフォルト | 集中25分・休憩5分                        |
| カスタム   | 新しいプリセットを作成・名前付き保存可能 |
| 上限       | 無制限                                   |

#### 4.6.3 プリセットで設定できる項目

| 項目               | 設定範囲         | 補足                                               |
| ------------------ | ---------------- | -------------------------------------------------- |
| 集中時間           | 25分〜上限なし   | ポモドーロ標準（25分）を下限とする                 |
| 休憩時間           | 5分〜10分        | 15分以上は「停止」「一時停止」で対応               |
| 通知音（集中終了） | 選択式（無音可） |                                                    |
| 通知音（休憩終了） | 選択式（無音可） |                                                    |

#### 4.6.4 プリセット管理

作成 / 名前変更 / 削除 / 利用中プリセットの選択

#### 4.6.5 設定値のバリデーション

| 条件           | エラー内容                                                   |
| -------------- | ------------------------------------------------------------ |
| 集中時間 < 25分 | 「集中時間は25分以上で設定してください」、保存拒否           |
| 休憩時間 < 5分  | 「休憩時間は5分以上で設定してください」、保存拒否            |
| 休憩時間 > 10分 | 「休憩時間は10分以内で設定してください」、保存拒否           |

#### 4.6.6 動作

| 項目         | 仕様                                     |
| ------------ | ---------------------------------------- |
| カウント     | 選択中のプリセットに従い集中→休憩        |
| 終了通知     | 通知要件に従う                           |
| 自動繰り返し | OFFがデフォルト（将来拡張）              |
| 休憩スキップ | 休憩中に「スキップ」で次の集中を開始可能 |

---

### 4.7 通知（音・画面）

#### 4.7.1 通知の種類

ポモドーロの「集中終了」「休憩終了」を通知

#### 4.7.2 通知手段（v2）

| 手段           | 設定         |
| -------------- | ------------ |
| 音             | ON/OFF       |
| ブラウザ通知   | ON/OFF（許可が必要） |

#### 4.7.3 デフォルト設定

| 項目     | デフォルト | 備考                                     |
| -------- | ---------- | ---------------------------------------- |
| 通知音   | OFF（無音） | 集中を妨げないため                       |
| 画面表示 | ON         | ブラウザ通知未許可時はアプリ内バナーで代替 |

#### 4.7.4 アプリ内通知の表示仕様

- 画面上部にバナー形式で表示
- 5秒後に自動消去（または手動で閉じる）

---

### 4.8 データ管理

#### 4.8.1 データ保持期間

| 項目           | 仕様                                     |
| -------------- | ---------------------------------------- |
| 保持期間       | 1年間                                    |
| 1年超データ    | 自動アーカイブ（通常の集計・グラフに含まない） |
| アーカイブ取得 | CSVエクスポートで可能                    |

#### 4.8.2 データ出力（バックアップ）

CSVエクスポート対象：
- プロジェクト
- セッション履歴（開始/終了/時間/メモ）
- アーカイブ済みセッション

※インポートは将来検討（v2は非スコープ）

---

### 4.9 認証・アカウント

**v2は個人利用想定。第三者が閲覧/操作できないこと。**

#### 4.9.1 ログイン

| 項目       | 仕様                                     |
| ---------- | ---------------------------------------- |
| 認証方式   | Google認証                               |
| アクセス制御 | 認証済みユーザのみデータアクセス可能   |
| 認証失敗時 | アプリ機能（閲覧/計測/編集）を利用不可   |

#### 4.9.2 ログアウト

- 設定画面からログアウト可能
- ログアウト後はログイン画面に遷移

#### 4.9.3 アカウント削除

v2では非スコープ（将来の公開版で実装）

## 5. 非機能要件

| 項目   | 要件                                                           |
| ------ | -------------------------------------------------------------- |
| 可用性 | 一般的なWebサービスとしてアクセスできること                    |
| 性能   | 直近1年分のセッションで一覧・集計が **3秒以内** にレスポンス   |
| 操作性 | プロジェクト選択→タイマー選択→計測開始をストレスなく行える     |
| 信頼性 | 通信断やブラウザクラッシュでも直近の計測状態が復元できる       |
| 保守性 | 後からログイン/複数ユーザ化しやすい構造                        |

### 5.1 計測中に通信遮断が発生した場合の挙動

| 状況           | 挙動                                                   |
| -------------- | ------------------------------------------------------ |
| 基本方針       | 通信状態に依存せず計測継続（集中を途切れさせない）     |
| 遮断検知時     | 「オフライン」表示、操作はローカル記録→復帰後に反映   |
| 計測中         | startAtをローカル保持、端末時刻ベースで経過時間表示    |
| ページ閉じ/再読込 | 次回起動時に「計測継続中」を復元                     |
| 通信復帰時     | ローカルのイベントを時刻付きで送信・反映               |
| 矛盾発生時     | セッションIDで重複防止、必要なら履歴画面で手動修正     |

### 5.2 複数端末での同時操作時の競合解決

| 項目       | 仕様                                     |
| ---------- | ---------------------------------------- |
| 基本ルール | 後勝ち（Last Write Wins）                |
| 競合時     | タイムスタンプが新しい操作を採用         |
| 手動対応   | 履歴画面で修正可能                       |

## 6. インフラ要件

- 外部サービスにデプロイし、インターネット経由で利用できること
- **サーバ保存（データベース）を採用**（PC/スマホ間で同じデータを参照）

## 7. 受け入れ条件（完成判定）

| No | 条件                                                               |
| -: | ------------------------------------------------------------------ |
|  1 | プロジェクトを作成/編集/アーカイブできる                           |
|  2 | 1プロジェクトのみ計測でき、開始/一時停止/再開/停止が動作する       |
|  3 | セッション履歴が一覧で見られ、手動修正できる                       |
|  4 | 日/週/月/年で集計が見られ、プロジェクト別の棒グラフが表示される    |
|  5 | 日/週/月/年で円グラフ（プロジェクト割合）が表示される              |
|  6 | ポモドーロ（25/5、カスタム可）が動き、通知ON/OFFが設定できる       |
|  7 | ポモドーロの休憩をスキップできる                                   |
|  8 | CSVエクスポートができる                                            |
|  9 | Google認証でログイン/ログアウトできる                              |
| 10 | 複数端末で同じデータを参照できる                                   |
| 11 | スマホでも「開始/停止」が迷わず操作できる                          |
| 12 | 記録の修正ができ、合計が正しく再計算される                         |
