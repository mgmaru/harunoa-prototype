# frontend-design Skill

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic aesthetics.

## Key Principles

**Design Thinking**: Before coding, understand context and commit to a bold aesthetic direction—whether brutally minimal, maximalist, retro-futuristic, or another distinctive style. The focus is intentionality over intensity.

**Core Guidelines**:
- Typography: Use characterful, unexpected fonts rather than generic choices like Arial or Inter
- Color & Theme: Commit to cohesive aesthetics with dominant colors and sharp accents
- Motion: Prioritize CSS animations with high-impact moments (staggered page load reveals, scroll-triggers)
- Spatial Composition: Employ asymmetry, overlap, diagonal flow, and grid-breaking elements
- Visual Details: Create atmosphere through gradients, textures, patterns, and decorative effects

**What to Avoid**: Generic AI aesthetics including overused fonts (Inter, Roboto), clichéd color schemes, predictable layouts, and cookie-cutter patterns lacking context-specific character.

**Implementation**: Match code complexity to your vision—maximalist designs need elaborate animations; minimalist designs require precision in spacing and typography. The output should feel genuinely designed for its specific context, never generic.
